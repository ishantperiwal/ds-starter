# Provenance and reference boundaries

Extracted from the local Titan CRM design-system and moodboard sources during this
conversation. `reference/titan-design-system/` is an unmodified snapshot of that
system, including historical documentation, schema, workbench, audit scripts,
component implementations, themes, visualizations and example fixtures.

That snapshot is not the active portable workbench. It retains CRM selectors,
routes, specimen assumptions and historical measurements. Do not run its measurement
scripts to assess a new project or interpret archived counts as current adoption.
Do not apply its owner-only editing policy instead of this starter's AGENTS.md.

`framework/examples/` uses copied reference styles/renderers with new fictional
screens and a curated demo registry. Those implementations are a sandbox dependency,
not preapproved project components. The framework's active registry/schema envelope
and generic workbench are new. The adapted inspector and moodboard remain based on
the original code and preserve their known heuristic limitations.

The icon source identifies Phosphor Icons, regular/light/thin/bold path data, as MIT
licensed, with attribution in components/icon.js. Other inherited illustrations,
brand geometry and any referenced assets should be reviewed before public distribution.
This extraction does not assert ownership or assign a new license to the original
project. package.json is private; choose an appropriate license and retain required
third-party notices before publishing a public package.

No credentials, .env files, CRM data directory, mailbox/persona data, existing
moodboard images, Git metadata or network integrations were copied. Some archived
reference examples still contain fictional CRM terminology; they are reference
contracts rather than live app data.
